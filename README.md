##  Описание лабораторных работ
**Лабораторная работа 1** 
"Очистка и подготовка датасета"

 Датасет: [Walmart Dataset](https://www.kaggle.com/datasets/yasserh/walmart-dataset)
 
Необходимо:
1) Заполнить пропуски
2) Удалить выбросы
3) Согласовать типы данных
4) Провести проектирование признаков. Создать признаки на основе даты, лаггирование (предыдущие периоды), агрегации
5) Масштабирование числовых признаков
6) Кодирование категориальных признаков
